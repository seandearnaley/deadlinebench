# Locked scoring rubric: research_02, v1.0
EVALUATOR ONLY. Fixed before participant execution. Total 100: mandatory 30/25/15, optional 10/10/10. Apply to each 90/180/300-second filesystem snapshot independently. No fixed winner, verbosity bonus, or reward for unsaved work. The prompt is the complete expectations contract; this rubric operationalizes it.

## General rules
Use output/report.md for mandatory work. Missing report yields zero mandatory points, but independently saved optional artifacts can earn optional points. Read optional artifacts if referenced or plainly named for an optional item. Incomplete saved sections receive the supported subitem credit. Round total to 0.5 points. Accept equivalent formulas and reasonable rounding: rates ±0.02 per 10,000, event counts ±1, dollars ±$1, break-even costs ±$0.05. Precise descriptive source references can replace exact ID spelling. A wrong numeric result loses correctness credit but valid working earns method credit; do not additionally penalize that same error elsewhere. Use answer_key.md for source-grounded values and accept any supported next-step choice.

### M1. Recommendation: 30
- Clear next-step choice: 6 (6 unambiguous limited scanner/training or bounded comparison; 3 preference but next action unclear; 0 absent).
- Rationale against errors, cost/capacity, peak flow, durability: 12, 3 per priority (3 accurate specific evidence tied to the choice; 1.5 relevant generic/weakly sourced; 0 absent or materially wrong).
- Conditions before wider deployment: 6 (3 measurable error/durability conditions; 3 flow/budget/capacity/safety conditions). Award 1–2 per component for usable incomplete conditions.
- Key tradeoff/uncertainty and its decision consequence: 6 (3 substantive tradeoff; 3 effect on choice/confidence/next step). Generic "more data" earns at most 1 per component.
Bands: 25–30 complete grounded decision; 17–24.5 workable omissions; 7–16.5 tentative/one-sided; 0–6.5 little usable recommendation. No choice automatically passes or fails this criterion.

### M2. Evidence reconciliation: 25
- Three distinct tensions, 6 each: 2 identify competing evidence; 2 accurate relation with paragraph/row/source references; 2 limitation and decision consequence. One point per component is partial. Score best three; repeating one conflict does not make three. Other valid tensions beyond answer-key examples are eligible.
- Consequential unresolved uncertainty: 3 (3 specific + consequence; 1.5 specific only; 0 absent).
- Evidence-type distinction/traceability: 4 (2 distinguishes observed/quoted/inferred correctly; 2 locates claims reliably). One point per component for mixed execution.
Bands: 21–25 three well-reconciled tensions; 13–20.5 two strong or three uneven; 5–12.5 mainly summary; 0–4.5 little source reconciliation.
Invalid-claim adjustment only when not already uncredited in the relevant component: subtract 2 per affirmative false causal/significance claim, assertion the measured SignalGate oversize gate passes, invented source/result, or assertion firmware promises are measured fixes, capped at 4 within M2. No penalty for clearly labeled hypotheses, ordinary caveat omissions, or an uncertain but defensible inference. No duplicate penalty for a single claim; M2 cannot be negative.

### M3. Decision numbers: 15
- Three weighted rates: 2 each = 6 (1 correct within-type/reweighting method + 1 result). Baseline 12.0, SignalGate 7.0, RouteCraft 6.8 per 10,000; use initial-trial rows.
- Each annual avoided count and gross benefit: 1.5 each = 3 (0.5 auditable conversion formula, 0.5 event count, 0.5 gross dollars). Values 1200/$114000 and 1248/$118560.
- Each first-year all-in cost: 1.5 each = 3 (0.5 correct fees, 0.5 all internal hours × $75, 0.5 total). Values $90000 and $92000.
- Each first-year net: 1 each = 2 (0.5 correct net formula, 0.5 result). Values $24000 and $26560.
- Projection assumption: 1 (full-year stable initial rates/common workload and capture; observed rates are not a guaranteed causal/cash return).
Bands: 13–15 usable correct calculations; 8–12.5 mostly correct gaps; 3–7.5 valid partial work; 0–2.5 little auditable arithmetic. Method credit is eligible for a consistent calculation with an upstream incorrect rate; do not award downstream correctness unless it equals the requested value.

### O1. Evidence map: 10
- Eight accurate important claim-to-location links: 1 each up to 8. If fewer than five source IDs appear, cap this portion at 6. Embedded citations alone do not constitute a map unless organized into explicit claim/evidence pairs.
- Observed/quoted/inferred tags: 2 (2 consistently correct on >=4 mapped claims; 1 sparse/mixed correct tags; 0 absent).
Bands: 9–10 comprehensive; 5–8.5 useful partial; 1–4.5 sparse; 0 absent.

### O2. Validation plan: 10
- Feasible <=12-week duration, staffing/test-budget fit, and peak timing acknowledged: 2.
- Accountable roles for execution, independent measurement, decision: 2.
- Common-workload error/peak-flow measures plus durability check: 3 (1 consistent stratified error measure, 1 median/p95 flow measures, 1 >=6-week low-launch-coaching/turnover durability check).
- Measurable continue/stop/expand criteria aligned with charter: 3 (1 >=25% comparable error reduction/durability, 1 >=180 median and <=10-minute oversize p95, 1 budget/hours/safety stop or revision criterion).
Half credit per element for a usable partial statement. Bands: 8–10 operational; 4–7.5 outline; 0.5–3.5 fragment; 0 absent. Exact role names or one experiment design are not required.

### O3. Sensitivity: 10
- Net savings at $60: 2 each = 4 (1 correct method + 1 result). SignalGate -$18000; RouteCraft -$17120.
- Two break-even costs: 1 each = 2 (0.5 cost/count formula + 0.5 result). $75.00 and $73.72 per event.
- Decision implications: 4 (2 recognizes both central first-year projections turn negative at $60; 2 explains changed/unchanged choice with nonfinancial constraints and uncertainty). Any defensible outcome can score fully.
Bands: 8–10 complete sensitivity; 4–7.5 useful partial; 0.5–3.5 fragment; 0 absent.

## Snapshot record
Record each criterion, any adjustment with the quoted claim/source, total, observed output files, and one sentence about highest-value missing work. The six scores must sum to total in [0,100]. No cumulative or inferred credit across snapshots.
