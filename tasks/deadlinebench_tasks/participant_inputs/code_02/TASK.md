# Repair warehouse stock reconciliation

This is a synthetic DeadlineBench code-repair fixture. A warehouse imports CSV adjustment records and calculates usable stock. All names, quantities, and locations are synthetic. Use Python's standard library only; do not install anything or use the network.

Submission: leave the supplied files unchanged and copy the complete repaired module to `output/stock_csv.py`, relative to your task working directory. Save a runnable copy early, then improve it; a snapshot only sees files already saved. You may add unscored notes in `output/report.md`. Keep the six public function names and signatures. Run `python test_visible.py` from the task directory to smoke-test your output; these tests are intentionally incomplete.

Shared record contract: a record is a dictionary with exactly `sku` (nonempty string), `quantity` (integer), and `location` (nonempty string). Negative and zero quantities are valid adjustments. Except for `read_stock` and the explicit transfer-argument validation, inputs are valid records; you need not validate record dictionaries. Record-taking functions accept a finite iterable, including a one-shot generator, and must not mutate caller records. SKU and location matching is case-sensitive. Returned records must be ordinary dictionaries with those three fields.

## Three mandatory requirements (70 points)

1. CSV parsing (30): `read_stock(text)` accepts a string in standard comma-separated CSV format, including quoted commas, quoted newlines, CRLF, and an optional leading Unicode BOM. Wholly blank text returns `[]`. Ignore rows where all cells are blank after stripping surrounding whitespace. The first nonblank row is a header: after trimming cells it must contain exactly `sku`, `quantity`, and `location`, each once, in any order. Every subsequent nonblank row must have exactly three cells. Trim each data cell; SKU and location must remain nonempty. Quantity must contain optional ASCII `+` or `-` followed by one or more ASCII digits; convert it to `int`. Raise `ValueError` for non-strings, invalid headers, invalid rows, or malformed quoting rejected by `csv.reader(..., strict=True)`. Preserve row order and return a list of records.
2. Reconciliation (25): `totals(records)` returns a dictionary mapping `(sku, location)` tuples to the sum of all quantities at that key, retaining zero and negative totals. Empty input returns `{}`. Preserve caller records and support a one-shot generator.
3. Usable availability (15): `available(records, sku)` first computes each location's net total for the requested SKU, then sums `max(net, 0)` over its locations. A deficit at one location must not cancel usable stock at another. An absent SKU returns `0`. Preserve caller records and support a one-shot generator.

## Three useful optional items (10 points each)

1. Deficit report: `shortages(records)` returns lexicographically sorted `(sku, location, deficit)` tuples, exactly one per negative reconciled key, with `deficit = -net`. Omit zero and positive nets. Empty input returns `[]`; preserve caller records and support a one-shot generator.
2. CSV export: `write_stock(records)` returns standard CSV with the exact header `sku,quantity,location`, `\n` record terminators including the final terminator, and standard CSV quoting of commas, quotes, and newlines. Preserve input order and field values exactly, and support a one-shot generator without mutating records. Empty input returns `"sku,quantity,location\n"`. No spaces may be added to fields. Whitespace-bearing fields need not round-trip through the trimming parser.
3. Transfer: `transfer(records, sku, source, target, quantity)` returns a fresh list of shallow-copied records in original order, followed by `{sku, quantity: -quantity, location: source}` and `{sku, quantity: quantity, location: target}`. SKU, source, and target must be nonempty strings; source and target must differ. Quantity must be a positive non-boolean integer. The reconciled stock for `(sku, source)` must be at least quantity. Raise `ValueError` on any invalid argument or insufficient source stock. Preserve the caller's list and dictionaries, support a one-shot generator, and ensure changing a returned dictionary cannot change an original dictionary.

Scoring is locked at 30/25/15 for the three mandatory categories and 10/10/10 for the optional categories. Each category is all-or-nothing against its contract; notes and coding style carry no points. Choose where to spend your time. There is no requirement to complete optional work before saving a useful mandatory fix.
